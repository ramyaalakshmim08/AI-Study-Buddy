# AI Study Buddy – Personalized Learning Assistant

## 📌 Project Overview

AI Study Buddy is a personalized learning assistant designed to help students organize their academic activities and manage their learning more effectively. It provides a centralized interface for managing study materials, notes, tasks, habits, goals, and focus sessions.

The application aims to make learning more organized by bringing essential student productivity tools together in one place.

## 🎯 Objectives

* Help students organize their academic tasks and study goals.
* Provide a centralized space for notes and learning materials.
* Support habit tracking and progress monitoring.
* Help students plan and manage their study activities.
* Provide an interactive interface for a more organized learning experience.

## ✨ Features

The application includes the following sections, depending on the features enabled in the current implementation:

* **Dashboard:** Overview of tasks, goals, habits, and focus activity.
* **AI Assistant:** Assistance with learning and organizing study activities.
* **Study Materials:** A space for managing learning resources.
* **Notes:** Organization of study notes.
* **Tasks:** Management of academic tasks.
* **Calendar:** A view for organizing schedules and important dates.
* **Habits:** Tracking of study habits.
* **Goals:** Management of learning goals.
* **Focus:** Support for focused study sessions.
* **Planner:** Organization of study activities.
* **Progress:** An overview of learning and productivity progress.
* **Themes:** Interface appearance options, where available.

## ⚙️ Installation and Setup

### Prerequisites

* Python installed on your computer
* pip package manager
* Git, if cloning the repository

### Steps

1. Clone the repository or download the project files.
2. Open a terminal in the project directory.
3. Create and activate a Python virtual environment.
4. Install the dependencies listed in `requirements.txt`.
5. Configure any required API keys or secrets using environment variables or Streamlit secrets.
6. Start the application using the command below.

```bash
streamlit run app.py
```

7. Open the local URL displayed in the terminal to access the application.

**Note:** The entry-point filename and setup requirements must match your actual project.

## 🚀 Deployment

The application can be deployed as a web app using Streamlit Community Cloud or another compatible hosting platform.

Before deployment:

* Confirm that the application runs locally.
* Ensure that `requirements.txt` contains the required dependencies.
* Configure API keys and secrets securely.
* Do not upload API keys, passwords, virtual environments, or private database files to a public repository.
* Test the deployed application after publishing.
